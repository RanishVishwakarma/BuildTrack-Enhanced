# BuildTrack Frontend

React 18 + Vite + Tailwind CSS (JavaScript). Setup steps are in the [root README](../README.md).

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # Vitest
npm run lint
npm run build
```

Set `VITE_API_BASE_URL` in `.env` (see `.env.example`) to the backend address including `/api/v1`.
